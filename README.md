# de_Hum

![de_Hum](image-1784219049433.png)

Карта для **Counter-Strike 2** (Source 2 / Hammer). Competitive defusal-режим (`de_`), сеттинг — **Backrooms** (белый вариант): бесконечный лиминальный лабиринт однообразных белых комнат с гудящими люминесцентными лампами. Два бомб-сайта, спавны T/CT, закупочные зоны, радар — сгенерирован через RadGen.

**Статус:** блокаут построен, первый playtest пройден, планты/buyzone/свет доведены до играбельного состояния. Готовится публикация в Steam Workshop.

## Структура репозитория

- **`de_zarya-design.md`** — полный дизайн-документ: идея темы, layout, принципы дизайна, порядок постройки, технический контекст и уже пройденные грабли (компиляция, спавны, свет, nav mesh).
- **`de_mygame/`** — содержимое аддона CS2 (`.vmap`, материалы, звуки, панорама, RadGen-проект и т.д.), копия из `content/csgo_addons/de_mygame/`.
- **`image-1784219049433.png`** — иконка/ава проекта.

## Технические заметки (кратко, подробности в дизайн-документе)

- Аддон в Workshop Tools называется `de_mygame` (имя файла карты менять не стали).
- Компиляция в Hammer: `F9` → Build Map → Fast Compile (без света, быстро) / Full Compile (со светом, медленнее).
- Запуск: обычный CS2 (не Tools-режим) → консоль → `map_workshop de_mygame de_mygame`.
- Спавны T/CT требуют Z ≥ 16 юнитов над полом, иначе движок помечает их invalid.
- Nav mesh для ботов — открытый вопрос, `nav_generate` не распознаётся в `-tools` режиме, нужно тестировать через обычный (не Tools) запуск игры.

Подробный лог решений и найденных грабель — смотри `de_zarya-design.md`.
