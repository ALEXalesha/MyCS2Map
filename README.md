# de_Hum

![de_Hum](image-1784219049433.png)

Карта для **Counter-Strike 2**, сделана в Source 2 / Hammer.

- **Режим:** соревновательный, с закладкой бомбы (`de_`).
- **Сеттинг:** **Backrooms**, белый вариант: бесконечный лабиринт одинаковых белых комнат под гудящими люминесцентными лампами.
- **Размер:** компактный, около 3000×3000 юнитов.
- **Что есть на карте:** два места закладки, спавны T и CT, зоны закупки, радар из RadGen, сетка навигации для ботов.

**Статус: играбельна, опубликована в Steam Workshop.** Остались мелкие доводки и необязательная детализация, см. ниже.

## Что в репозитории

- **`de_zarya-design.md`** — полный дизайн-документ: идея темы, схема, принципы, что сделано, открытые задачи и пройденные грабли (компиляция, спавны, свет, nav mesh, боты). Название в имени файла историческое: раньше карта называлась de_Zarya.
- **`de_mygame/`** — содержимое аддона CS2, копия из `content/csgo_addons/de_mygame/`:
  - `maps/` — карта `de_hum.vmap`;
  - `materials/`, `postprocess/`, `panorama/`;
  - `RadGen/` — проект радара;
  - `soundevents/`, `sounds/` — звуки, см. раздел ниже.
- **`image-1784219049433.png`** — иконка проекта.

## Звуки — не наши

Звуки в `de_mygame/sounds/` (птицы, вентиляция, гул помещения) **взяты из Steam Workshop**. Их авторы и лицензии нам неизвестны. Поэтому:

- в этом репозитории на Gitea они лежат как рабочая копия;
- **в публичную версию (GitHub) папка `sounds/` не попадает.** Вместо неё README объясняет, какие звуки нужны, и `soundevents` ссылаются на них по именам.

## Как собрать и запустить

- Аддон в Workshop Tools называется `de_mygame`. Имя файла карты менять не стали.
- Hammer: Workshop Tools → Launch Tools → Asset Browser → иконка Hammer.
- Компиляция: `F9` → Build Map → **Fast Compile** (без света, быстро) или **Full Compile** (со светом и кубмапами).
- Запуск для теста с ботами — обычный CS2, не режим `-tools`. Консоль: `map_workshop de_mygame de_hum`.

## Главные грабли (подробно — в дизайн-документе)

- Спавны T и CT должны стоять минимум на 16 юнитов над полом, иначе движок считает их неверными.
- Нужна точка `info_player_start` в дополнение к спавнам T и CT.
- Коробка карты должна быть полностью замкнута, иначе при компиляции будет `leak`.
- Nav mesh не генерируется с ошибкой «no walkable seeds»: нужна сущность `point_nav_walkable`.
- Навык ботов меняет `custom_bot_difficulty 0–3`. `bot_difficulty` на него не влияет.
- Чёрные руки и оружие лечатся объёмом `env_combined_light_probe_volume`.
- Радар в Workshop может разойтись с локальным, если опубликовать карту до `Save Radar Image` в RadGen.
